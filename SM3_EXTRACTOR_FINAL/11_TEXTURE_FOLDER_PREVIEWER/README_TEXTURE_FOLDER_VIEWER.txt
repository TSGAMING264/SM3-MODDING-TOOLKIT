SM3 + WOS Texture Folder Previewer v0.9 - Strong Reveal Jump Fix
Released by TSGAMING264

What this build fixes:
- Reveal in Explorer should jump/select the exact selected image better.
- Uses Explorer /n,/select through Windows ShellExecute first.
- Keeps fallback Explorer /select behavior.
- Prefers the focused/clicked row instead of an older first multi-selected row.
- Keeps the v0.8 size search and filter options.

How to run:
1. Double-click RUN_VIEWER.bat
2. Select a DDS/image folder.
3. Click an image row.
4. Click Reveal in Explorer.

Expected behavior:
Explorer should open and highlight the exact selected DDS/image.
