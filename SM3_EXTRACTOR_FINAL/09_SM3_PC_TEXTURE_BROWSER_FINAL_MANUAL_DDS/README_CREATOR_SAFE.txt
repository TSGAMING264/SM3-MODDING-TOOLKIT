THE TEX SWAPPER - CREATOR SAFE v1.1
Created by TSGAMING264

This is the cleaner send-out build. It is separate from the full personal work build.

Main workflow buttons kept:
- EXPORT ALL DDS
- ONE FILE AUTO: File First -> Patch
- SELECTED CONVERT: Image/DDS -> Target Format
- AUTO Detect Edited DDS + Patch
- Set Replacement Folder
- REIMPORT ALL DDS FOLDER -> ONE PACK
- SMART REIMPORT: Exact + Convert Mips -> ONE PACK
- Open Output Folder / Open Replacement Folder

Recovery / Advanced buttons kept:
- TEST Safe Edited DDS + Patch
- RESTORE: All TEX from Clean Original Pack
- BUGCHECK: Scan Current Targets
- CONTROL: Original Selected Texture
- Dump Component0/1
- BATCH Export DDS for Selected
- Patch COPY with Replacement
- CONTROL: Full Original-Texture Self Test
- MANUAL OPTIONS CHECK

Basic use:
1. Run RUN_THE_TEX_SWAPPER_CREATOR_SAFE.bat.
2. Browse to a clean SM3 PCPACK.
3. Click Build Preview.
4. Export/edit/reimport textures into a NEW PCPACK copy.
5. Always keep a backup of the original PCPACK.
