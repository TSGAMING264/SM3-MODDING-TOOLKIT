SM3 Beta Pack Extractor v2.27 - Megacity Theme Release UI
Created by TSGAMING264

This is the clean standalone Spider-Man 3 PC pack extractor beta.
It uses the proven route-handler backend but keeps the front-end release-style and simple.

What's new in v2.27:
- Megacity Tool dark-mode color match.
- Blue EXTRACT PACK button replaces the old green RUN EXTRACTION button.
- Cleaner release-style presentation while keeping the v2.25 extraction behavior.

Main workflow:
1. Select one SM3 .PCPACK.
2. Select an output folder.
3. Click List Contents to preview resources.
4. Click EXTRACT PACK.
5. Use Open Output or Open Pack Browse.

Safety:
- Original PCPACKs are never modified.
- Force only backs up/replaces old extracted output folders under output/backups.
- Research/dev controls are hidden in this beta UI.
- Release cleanup removes temporary 00_REPORTS, 00_MASTER_REPORTS, and report zip bundles after List Contents or extraction.


v2.27 note: Main EXTRACT PACK button changed from bright blue to a darker slate/blue release-style button. No extraction backend behavior changed.
